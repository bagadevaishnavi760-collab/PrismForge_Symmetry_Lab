The Art of Calm: Benefits of Mandala Drawing

Mandalas are circular, often symmetrical patterns made with repeated shapes, lines, and geometric designs. Drawing one can be a relaxing creative activity for some people, while its repetition and symmetry offer a friendly bridge to the ideas explored in computer graphics.

Mindfulness

✎

Creativity and Self-Expression

Colours, shapes, and patterns let you explore your artistic ideas.

◇

Patience and Precision

Project information

PrismForge: Symmetry Lab

An interactive Computer Graphics mini-project for exploring rotational symmetry, reflection, rasterization, and generative drawing directly in the browser.

Overview & objectives

PrismForge turns low-level graphics ideas into a playful canvas experience. Draw a stroke once and watch the symmetry engine repeat it around the canvas, or switch to generated geometric modes for a faster visual study.

Explore symmetry

Understand how rotation sectors and optional mirror reflection create dihedral-style patterns from a single gesture.

Connect theory to pixels

Use the algorithm explorer and separately compilable C implementations to study how classic rasterization methods produce points.

Experiment visually

Change brush size, opacity, color, and drawing modes while keeping the feedback immediate and interactive.

Graphics algorithms

These cards distinguish what is implemented in the project from concepts surfaced for learning.

Implemented in C

DDA line

Steps along the dominant axis, increments the other coordinate, and rounds each position into an integer pixel. See pf_dda_line.

Implemented in C

Bresenham line

Uses an integer error term to choose the closest pixels efficiently across all octants. See pf_bresenham_line.

Implemented in C

Midpoint circle

Uses a decision variable and eight-way symmetry to plot circle points with integer increments. See pf_midpoint_circle.

Implemented

2D transformations

The browser applies center-relative rotation and optional reflection in JavaScript; the C module also provides pf_transform_point.

Implemented in browser

Rotational symmetry & reflection

Each pointer segment is repeated through the selected sectors and, when enabled, its reflected copy. This powers the live canvas.

Conceptual only

Flood fill

The explorer explains seed-based connected-region filling, but no flood-fill tool is implemented in the current canvas.

Verified features

  • Live kaleidoscope drawing with seven selectable sectors, reflection, rotation, and guides
  • Brush, eraser, gradient, glow, neon, light-trail, background, and named palette controls
  • Generated mandalas with ten complexity levels, five presets, and editable ring layers
  • Colouring Book templates with bounded vector-region fill and reset / erase controls
  • My Gallery with local save, preview, rename, duplicate, delete, reopen, and JSON backup
  • Polygon, spiral, fractal, and demo drawing modes
  • Undo, redo, confirmed clear, fullscreen, and mindful mode
  • High-resolution PNG export and editable project JSON
  • CG Algorithm Explorer with separate C source demonstrations

Learning outcomes

Reason about coordinates

Practice translating points around a center, applying trigonometry, and mapping them back to the canvas.

Compare rasterization

See why DDA and Bresenham make different trade-offs while midpoint circle uses symmetry to reduce work.

Build interactive graphics

Connect semantic controls, pointer events, canvas rendering, and a small Flask server into one focused project.
